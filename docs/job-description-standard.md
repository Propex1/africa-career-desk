# Job description standard

Use the Investment Associate, DRE – Africa50 page as the editorial model. Apply this rule to every new or revised job and programme, including local previews.

1. **Summary:** normally 35–65 words, explaining the role, investment or finance focus, location and purpose. Avoid generic employer promotion.
2. **About the role:** normally 50–110 words of additional context: team, reporting line, mandate, asset classes, geography and working arrangements, only where the source states them. Never repeat the summary.
3. **Key responsibilities:** normally 5–7 meaningful bullets, explaining actual work and outputs. Group related tasks; preserve distinguishing responsibilities.
4. **Key requirements:** normally 4–6 meaningful bullets. Retain exact experience thresholds, degrees, languages, work permissions, nationality, travel and other eligibility constraints. Distinguish mandatory from preferred requirements and preserve alternative qualification routes. More bullets are acceptable when needed to retain material restrictions.
5. **Application notes:** short, actionable facts about how to apply, uncertainties, inconsistent requirements or deadlines. Do not show private owner comments as public copy.

These are content targets, not quotas. Do not invent details or split generic claims to reach a count. If the original advert is sparse, retain a shorter evidenced description, state the specific limitation and record an editorial exception. Do not infer experience, degree, remote work, compensation, eligibility or permanent employment.

## Sources and Apply destinations

- Read the complete employer advert or authorized ATS record, including the full requirements. Dashboard snippets and truncated feed text are insufficient when a complete source is accessible.
- Search the official employer career site for the same role before retaining a LinkedIn, recruiter, general careers or form link. Match employer, title, location and requisition identity.
- Prefer the employer's exact job-description page, with its onward application route; otherwise use the authorized ATS job-detail page. For example, Standard Bank's verified `job-detail?jobID=...` page is preferred to a generic page or immediate form.
- A successful HTTP response, URL pattern or matching title alone does not verify a destination. Confirm that the page renders the correct role, meaningful description and application instructions. Keep a timestamped capture and record redirects or failures.
- If no matching employer listing can be verified, retain a clearly attributed usable recruiter/employer-post source and disclose the limitation. Never replace it with an unrelated role or generic homepage.
- Use **View role and apply** when the button opens the role description; use **View job description (PDF)** for a PDF and explain the application route.
- Source verification and editorial completeness do not authorize publication. Owner acceptance, rejection, notes, evidence, first-publication history and ranking must survive content revisions. Material changes require owner review before publication.

## Validation

Run `npm run acd:content:check`. Source limitations are recorded in `src/data/job-description-exceptions.json`; private review notes must remain outside the public repository. Preserve existing first-publication dates when refreshing listings.
